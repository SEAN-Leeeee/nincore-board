--- 

- 프로젝트 목표
  농구 동호인을 위한 점수판 프로그램. 가격이 비싼 점수판을 구매하지 않아도 같은 기능을 아이패드와 같은 디스플레이로 보고, 핸드폰으로 조작할 수 있게 구현했습니다.

---

- 주요 기능
  1. 웹 소켓 통신으로 리모트 - 서버 - 디스플레이 구조 설계
  2. 리모트로 조작하면 디스플레이에서 보여주는 방식
  3. 선수 개개인의 기록을 pdf로 변환하여 다운로드 가능 -> 추후 NINNong에서 자동 연동 기획중
